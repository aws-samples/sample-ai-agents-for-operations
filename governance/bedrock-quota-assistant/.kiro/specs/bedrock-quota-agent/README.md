# Spec: Bedrock Quota Agent

This directory contains the spec history for the Bedrock Quota Assistant agent.

## Agent Overview

- **Pattern:** AgentCore Runtime (Pattern #1)
- **Framework:** Strands Agents SDK
- **Compute:** Amazon Bedrock AgentCore Runtime (serverless)
- **Purpose:** Help customers understand Amazon Bedrock usage, compare utilization against quotas, and create quota increase requests
